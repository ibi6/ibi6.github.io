首屏背景不是装饰图，是过去一年的 GitHub 贡献：一格一天，提交越多楼越高。

## 等距投影就两行

把格子坐标 `(col, row)` 换成屏幕坐标：

```js
const sx = (col - row) * tileW / 2;
const sy = (col + row) * tileH / 2 - height;
```

每栋楼画三个面：顶面最亮，左右两个侧面依次变暗，立体感就出来了。

## 画的顺序很重要

从远到近画（`col + row` 小的先画），近处的楼才能盖住远处的。顺序错了会出现穿模。

## 让它活起来

- 楼按距离依次长出来，用一个带延迟的缓动
- 鼠标指到哪栋，哪栋抬高并显示日期和次数
